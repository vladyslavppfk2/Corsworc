# АІС управління навчальним процесом коледжу
Виконав: Дерієнко Владислав, 44 група

Настільний застосунок для обліку груп, студентів, викладачів, дисциплін та оцінок.
Реалізовано на **Python + Tkinter + SQLite** без сторонніх залежностей.
 
## Можливості
 
- CRUD-операції (додавання, редагування, видалення) для груп, студентів, викладачів, дисциплін та журналу оцінок
- Пошук за будь-яким полем у кожній таблиці
- Випадаючі списки зі зв'язаними довідниками (група студента, викладач дисципліни тощо)
- Звіт про успішність: кількість оцінок і середній бал по кожному студенту з фільтром за групою
- Валідація даних: обов'язкові поля, числові значення, оцінка в межах 1–100
- Заповнення бази демо-даними через меню **Файл → Заповнити демо-даними**
## Вимоги
 
- Python 3.8 або новіший
- Tkinter (входить до стандартної збірки Python; на Linux може знадобитися пакет `python3-tk`)
## Запуск
 
```bash
AIS_College.exe
```
 
Під час першого запуску автоматично створюється файл бази даних `college.db`.
 
## Структура проєкту
 
| Файл | Призначення |
|------|-------------|
| `main.py` | Точка входу, головне вікно, меню та вкладки |
| `database.py` | Робота з SQLite: створення таблиць, виконання запитів, демо-дані |
| `base_tab.py` | Універсальна вкладка CRUD (форма, таблиця, пошук) |
| `tabs.py` | Опис вкладок: групи, студенти, викладачі, дисципліни, журнал оцінок |
| `report_tab.py` | Вкладка звітів про успішність |
 
## Структура бази даних
 
- `groups` — назва, спеціальність, курс
- `students` — ПІБ, дата народження, телефон, група
- `teachers` — ПІБ, посада, телефон
- `subjects` — назва, кількість годин, викладач
- `grades` — студент, дисципліна, оцінка, дата
Зв'язки та правила цілісності:
 
- видалення групи: `students.group_id` встановлюється в `NULL`
- видалення викладача: `subjects.teacher_id` встановлюється в `NULL`
- видалення студента або дисципліни: пов'язані оцінки видаляються каскадно
- оцінка обмежена перевіркою `CHECK(grade BETWEEN 1 AND 100)`
## Технології
 
- Python 3
- Tkinter / ttk
- SQLite 3 (модуль `sqlite3`)
